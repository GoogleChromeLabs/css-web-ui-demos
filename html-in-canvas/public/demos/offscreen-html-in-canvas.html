info Demo overview

This demo operates across two execution threads. The main thread renders the page DOM and animates the background text. The Web Worker controls the OffscreenCanvas off-thread. When DOM subtree elements change, canvas.captureElementImage() captures the bitmap and posts it to the worker, where ctx.drawElementImage() renders it off-thread. Because Web Workers do not have access to the DOM, the worker returns the calculated transform matrix back to the main thread, where it is applied to formElement.style.transform to align layout and hit-testing bounds.

Offloading rendering to an OffscreenCanvas keeps the main thread responsive even when the worker thread is overloaded or frozen. Try freezing the worker thread to observe that main-thread background animations and UI interactions remain unaffected. Conversely, if the main thread is frozen, DOM paint events (canvas.onpaint) cannot execute, preventing updated element snapshots from being captured and sent to the worker.
