HTML-in-Canvas with TypeScript

The card below is real HTML drawn into a 2D <canvas> with ctx.drawElementImage(), rotated by the canvas transform, and still fully interactive. The code is strict TypeScript, typed by @types/dom-html-in-canvas. Read the HTML-in-Canvas explainer to learn more.

Your browser doesn't support HTML-in-Canvas yet. Try this demo in Chrome 157 or later.
