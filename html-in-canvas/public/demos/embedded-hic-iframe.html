web Embedded HTML-in-Canvas

This demo shows how the HTML-in-Canvas feature works when canvas is embedded in an iframe. The page embeds an iframe from chrome.dev that is currently signed up for an origin trial. So, the HTML-in-Canvas feature should work in browsers where the feature is implemented behind a flag even when the flag is not enabled.

verified Origin Trial Integration

Origin Trials allow web applications to enable experimental features on specific origins. Because chrome.dev registered an Origin Trial token, the embedded iframe executes with HTML-in-Canvas capabilities enabled regardless of parent frame settings.
