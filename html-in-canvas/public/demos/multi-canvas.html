info Demo Overview

This demo demonstrates rendering 10 separate <canvas> elements on a single webpage. Each canvas element encapsulates its own HTML DOM subtree, which is captured via ctx.drawElementImage(). Interactive form controls (inputs and buttons) inside all 10 canvas elements remain fully focusable and operational.
